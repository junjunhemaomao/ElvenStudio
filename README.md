# ELVEN STUDIO 网站本地重建版

2006 年 elvenstudio.com（成都轻灵／精灵数码，游戏美术外包公司）整站镜像的重建版。
原始文件在 `D:\web`，全部压平在一个目录里，HTML 里写的又是原始的相对路径，直接双击打开是坏的。
这个目录是重新拼装过、并且已经按现代网站重做的版本。

> **这个目录就是成品，以后直接在它里面改。** 换图、调 HTML 都在这儿动。
>
> **这里是一个 git 仓库。** 每完成一块都提交过，改坏了随时 `git log` 找到上一个提交回退。
> 三个关键节点：
>
> - `a4abc0a` — **2006 年原版**。HTML 4.01 + `<table>` 拼版面，全黑，布局一处没动
>   （只改了路径、编码，`.jpg` 换成了实际存着的 `.png`）
> - `7db9e68` — 把上面那版用 flex/grid 重表达 + `transform: scale()` 铺满大屏，
>   和原版逐像素对得上
> - `418b0fa` — **本版：推倒重做的现代站点**
>
> `a4abc0a` 那份原版整份冻在 **`D:\web_local_2006`**（可浏览，双击里面的 `启动.cmd`）。
> `7db9e68` 没有单独的目录副本，但提交在本仓库历史里，要看得开个 worktree 或者 `git checkout`。

## 怎么看

双击 `启动.cmd`，或者手动：

```
cd D:\web_local
python -m http.server 8765
```

然后浏览器打开 <http://127.0.0.1:8765/>。

走 http 更稳妥（`file://` 下有些浏览器的相对路径行为不一致）。手机上想看得开"允许局域网访问"，
用电脑的局域网 IP 加 `:8765` 打开。

## 目录

- `index.html` — 入口，双语开场页，选中文 / ENGLISH
- `gb/` — 简体中文版：`index` `about` `3d` `2d` `contact`
- `en/` — 英文版（镜像里这个目录原来的名字和内容对不上，重建时就按语言拆成了 `en/`）
- `gb/gallery/`、`en/gallery/` — 044 / 045 / 046 三个项目画册

- `assets/flash/` — 两个原始 SWF，加上从 01-f001.swf 转出来的动态 WebP

## 这一版是怎么做的

上一版把 2006 年那套 1024×768 的表格拼图用 flex/grid 原样重表达，定宽舞台加
`transform: scale()` 铺满大屏。它和原版逐像素对得上（最大偏差 1px 上下），但**它长得
就是 2006 年的网站**——所有设计都"烤"在图片里，版面是图片拼出来的。所以这一版推倒重来：

1. **烤在图里的字全部换成真文字。** 导航按钮、页面标题（「三维制作」「ABOUT US」）、
   小节标题、版权行，原来都是 PNG 切片，现在都是 HTML 文本，能选中、能被搜索、
   能换字体、手机上能正常折行。
2. **版面走正常文档流。** 没有定宽舞台，没有 `transform: scale()`。作品网格靠
   CSS Grid 的 `auto-fill` 自己算列数，全站只有三档断点（960 / 640 / 1400）。
3. **入口从三道门收成一道。** 原来根目录选语言 → 语言站开场页点 ENTER → 正文，
   现在是根目录双语开场 + 语言站首页直接就是内容页。
4. **加了内容首页。** 原来两个语言站进门是一张"点 ENTER 进入"的图，现在是真的首页：
   主视觉 + 作品精选 + 两项服务 + 一段简介。
5. **作品缩略图变成能点的。** 挂了灯箱：点开看 4 倍大，`←` `→` 翻页、`Esc` 关、
   焦点锁在灯箱里。原来 202 个缩略图点开就是在当前标签页开一张 63×63 的图。
6. **画册页不再是一整页白。** 原来 4~5 张 800px 宽的白底占位图上下堆，满屏白。
   现在封面 + 一句说明 + 占位图排成统一的白框网格，一眼看完。
7. **顺手补齐现代页面该有的东西**：吸顶导航、手机汉堡菜单、跳过导航的 skip link、
   `:focus-visible` 焦点圈、`prefers-reduced-motion`、打印样式、每页写实的
   `<title>` 和 `<meta name="description">`。

**一条没变的规矩：不改图片文件本身。** 不裁、不抠背景，只用 CSS 缩放和摆放。
背景也必须保持黑色——每张图的底色都烤成了黑色，换浅底会满屏黑方块。

## 哪些字是原来的，哪些是新写的

**照抄原文、一个字没改的：**

- `gb/about.html`、`en/about.html` 的全部正文（公司简介 / 参与项目 / 管理团队、
  The Studio / We have worked with / Our projects 的说明文字）
- 客户名单、项目盒绘的说明文字
- 两版页脚的版权行
- 联系方式页的地址、电话、邮箱

**新写的（原站没有这些文案）：**

- 两个首页的标题和一句话定位。「从三维角色到二维原画」「Elven Studio is a game
  production company in Chengdu…」这类句子是我按公司实际业务拟的，**不是原文**。
  原站的首页只有一张图和两个按钮。
- 首页「作品精选」「我们做什么」两个小节的标题，以及两张服务卡片的介绍文字。
- 首页「关于」那一节是例外：它是 `about` 页正文头两句，**逐字照抄**。
- 导航里新增了「关于我们 / About Us」一项。原站两个语言站的导航都只有
  返回首页 / 三维制作 / 二维设计 / 联系方式，about 页要从别处绕进去。
- 画册页那段解释（"原版把这一页的每张图都写死 800 宽铺出来……"）和
  `legacy-flash.html` 整页文案，都是这次写的说明。
- 页面标题、meta 描述、灯箱里的图注。

**中文站那 4 个小节标题是补的。** 公司简介 / 参与项目 / 项目展示 / 管理团队——
原版这 4 处是 4 张 95×17 的空白图（`01-bj022~025`），渲染出来就是四条白杠，图里没字。
英文站有真实标题图（"The Studio" "We have worked with" "Our projects"），中文站没有对应图，
所以这四个词是按上下文拟的。另外**英文站只有 3 个小节，中文站有 4 个**——
"管理团队"那节英文站本来就没有。这是原站就这样，不是这次漏了。

**公司名原站自己就不统一**：页面标题里写「精灵数码」，about 正文里写「轻灵数码」。
照抄，没统一。

## 以后怎么改

**改版面**：改 `assets/css/site.css`。文件分五段——令牌/reset、排版、骨架
（容器/页头/页脚/分区）、组件、断点。断点只有三档，其余尺寸靠 grid 的 `auto-fill`
自己算。改完刷新浏览器即可，没有构建步骤。

**改页面结构**：18 个页面是 `D:\_elven_tools\gen_site.py` 生成的，页头/页脚/导航/灯箱
都在那个脚本里，改一处全站生效。改完重新跑一遍：

```
python -I -X utf8 D:\_elven_tools\gen_site.py
```

生成出来的 HTML 就是成品，**站内不依赖那个脚本**（删掉工具目录网站照跑）。
不想用它也行，直接改 HTML——只是以后改导航要改 18 个文件。

**换图**：把同名文件覆盖进 `assets/image/`，HTML 不用改。
图片统一是 `.png`（原 HTML 里写的是 `.jpg`，磁盘上实际都是 png）。
尺寸不一样的话，记得把 HTML 里那个 `width`/`height` 属性一起改，否则会先按旧尺寸占位再跳一下。

## 验收

`D:\_elven_tools\verify.py` 会跑完这一串断言（18 页 × 5 个视口 + 交互）：

- 控制台无 error、页面无未捕获异常
- 没有任何请求失败（404 等）
- **不出现横向滚动条**
- 每张 `<img>` 都真的加载出来了
- 每张 `<img>` 都有 `alt` 属性
- 所有站内链接都能落到实际文件（现有 105 条）
- 390px 下汉堡菜单能开、能关、`Esc` 能收、`aria-expanded` 跟着变；宽屏下强制展开
- 灯箱：点缩略图能开、方向键能翻页、`Esc` 能关、有图注；画册页封面也能点开

`shoot.py` 是批量截图（`python -I shoot.py 输出目录 宽 高 [页面别名...]`），
`measure.py` 量单个页面每个元素的绝对位置，`cmp.py` 把本站和 baseline 逐元素比对
（比对是上一版逐像素重建时用的，这版已经不做像素对齐了）。
