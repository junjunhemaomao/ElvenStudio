# ELVEN STUDIO 网站本地重建版

2006 年 elvenstudio.com（成都轻灵/精灵数码，游戏美术外包公司）整站镜像的重建版。
原始文件在 `D:\web`，全部压平在一个目录里，HTML 里写的又是原始的相对路径，直接双击打开是坏的。
这个目录是重新拼装过、并且已经按现代浏览器重做过版面的版本。

> **这个目录就是成品，以后直接在它里面改。** 换图、调 HTML 都在这儿动。
>
> **这里是一个 git 仓库。** 每完成一块都提交过，改坏了随时 `git log` 找到上一个提交回退。
> 最初那一版（还没做这次改造的原始状态）是 `a4abc0a`。

## 怎么看

双击 `启动.cmd`，或者手动：

```
cd D:\web_local
python -m http.server 8765
```

然后浏览器打开 <http://127.0.0.1:8765/>。

走 http 更稳妥（`file://` 下有些浏览器的相对路径行为不一致）。手机上想看得开"允许局域网访问"，
用电脑的局域网 IP 加 `:8765` 打开。

## 目录

- `index.html` — 入口，选中文 / 英文
- `gb/` — 简体中文版（关于我们 / 三维制作 / 二维设计 / 联系方式）
- `en/` — 英文版（镜像里这个目录叫 `zh`，但装的是英文内容）
- `gb/gallery/`、`en/gallery/` — 044 / 045 / 046 三个项目画册
- `legacy-flash.html` — 2003 年版 Flash 首页的存档说明页
- `assets/css/site.css` — **全站唯一的样式表**，所有版面都在这里
- `assets/js/site.js` — 唯一一段脚本，只干一件事：大屏等比缩放
- `assets/image/` — 全部图片，199 个
- `assets/flash/` — 两个原始 SWF，加上从 01-f001.swf 转出来的动态 WebP

## 这次改了什么

一句话：**HTML 结构和 CSS 全部重做了，图片一个像素都没动。**
所有设计都"烤"在 199 张 PNG/GIF 里（它是表格拼图，不是可复用的素材），
所以只能重写外面这层骨架，图照原样摆回原位。

### 1. 版面：给 1024×768 排的东西，现在能铺满任何屏幕

原站所有宽度写死（359 / 654 / 660 / 673 等），字号硬编码，每个页面尾部挂着 IE 时代的
VBScript 死代码。现在的做法分两段：

- **屏幕宽 ≥ 820px**：CSS 恢复原来那套像素几何（数字全部来自对原页面的实测，
  元素 `getBoundingClientRect` 量出来的，不是估的），再由 `site.js` 整体 `transform: scale()`
  按视口高度放大铺满，放大上限 2×（再大 PNG 就明显发虚）。窗口比版面窄时自动缩小，
  不出现横向滚动条。
- **屏幕宽 < 820px**：不走缩放，直接退回正常文档流——页头图撑满宽度、正文按可读字号自然换行、
  缩略图网格按宽度自动列数。手机上不再是一整张缩到看不清的图。

顺带补齐了现代页面该有的东西：HTML5 doctype、`charset=utf-8`、`viewport`、
`<html lang>`、每页写实的 `<title>`（原来有 5 页叫 `Untitled Document`）、所有图片的 `alt`。

### 2. 去掉 iframe，正文直接内嵌

about / 3d / 2d 三页的正文原本塞在 `<iframe>` 里（定死 297×370 / 565×443），
长内容要在一小块里滚动。现在正文直接内联进页面，原 iframe 的位置换成可滚动的
`<div class="pane">`，滚动条配色用 `scrollbar-color` 和 `::-webkit-scrollbar` 实现
（替掉原来那套 IE 专有的 `SCROLLBAR-FACE-COLOR` 之类）。

6 个 `*-content.html` 随之作废，已删除（原始版本在 `D:\web`，也在 git 里）。

### 3. 干掉 Flash

about 页顶部那条 612×184 的横幅原本是 SWF，一个页面要下 14MB wasm 才跑得起来。
现在换成了同尺寸的动态 WebP（`assets/flash/01-f001.webp`，10.6 秒无缝循环），
`ruffle/` 目录（28MB）整个删掉。原始 SWF 两个文件原样保留在 `assets/flash/`。

`legacy-flash.html` 是 2003 年那版 Flash 首页，全站没有任何页面链接它，纯属存档。
它现在只展示第一帧静态图，不加载任何播放器；想还原动画可以用 Ruffle 独立播放器打开原 SWF。

### 4. 202 个死链缩略图

缩略图原本都包着 `<a target="ss_viewer">`，但页面上根本没有叫 `ss_viewer` 的框，
点开就是在当前标签页打开一张 63×63 的图。而且这些链接指向的文件**本身就是缩略图**，
镜像里没有大图，点开等于没点。所以除 3d-044/045/046 三张本来该跳画册页的之外，
其余 `<a>` 全部去掉。**以后拿到大图，把 `<img>` 套回 `<a href="大图">` 就能恢复点击。**

### 5. 画册页重做

`gallery/044|045|046` 原本是白底裸图 + `<table align="center">`，跟整站黑底完全脱节，
还把 63×63 的封面缩略图写死成 800×800 拉大铺出来。现在改成黑底居中 800px 宽的普通页面，
每张图按**真实尺寸**显示，封面单独标出"原图缺失"。

### 6. about 页的四条白杠

中文版正文里原本有 4 张 95×17 的纯白（其实是空图）占位图 `01-bj022~025`，
渲染出来就是四条白杠。换成了 CSS 文字小标题，配色对齐英文版真实标题图的黄色 `#d4c32f`。
**这四个标题是按上下文补的，不是镜像原文**——见下面的「待办」。

### 7. 顺手修的原站 bug

- `gb/2d.html` 的「返回首页 / 三维制作」指向 `../en/...`，跨语言了 → 改回 `gb/`
- `gb/contact.html` 的「返回首页」指向 `../en/about.html` → 改回 `gb/about.html`
- `en/3d.html`、`en/2d.html` 的导航按钮图没套链接（中文版套了）→ 统一成可点
- `gb/about.html` 里 `<script src="../../">` 是死引用，浏览器拿目录页当 JS 解析，
  控制台直接报错 → 删掉
- 英文页三个画册链接的 `title`/`alt` 原本是中文 → 改成英文

## 为什么这么改

- **为什么大屏要放大而不是居中留黑边**：这些图是按 1024×768 画的，在 2560 宽的屏上
  缩在中间只占四成宽，看着像坏了。等比放大到铺满是最接近"当年满屏浏览"的效果，
  代价是超过 1.4× 之后 PNG 会有点软——所以卡了 2× 的上限。
- **为什么断点选 820px**：最宽的一页是 696px。比它宽才谈得上"定宽版面 + 缩放"，
  再窄就该老老实实走文档流了。
- **为什么用 `transform: scale()` 而不是 `zoom`**：`zoom` 各浏览器行为不一致，
  而且 FireFox 长期不支持。`scale` 的坑是 `transform` 不改变布局盒子——
  所以 `site.js` 会把外层 `.fit-inner` 的宽高显式设成缩放后的尺寸，并让
  `transform-origin` 停在左上角，否则整版会往左偏一半。
- **为什么不重做图片**：一来没有原始设计文件，重画就是另一个设计了；
  二来这站的价值有一半就在于"2006 年长什么样"。所以原则是图不动，只动骨架。

## 以后怎么改

**换图**：直接把同名文件覆盖进 `assets/image/`，HTML 不用改。
注意站里图片统一是 `.png`（原 HTML 里写的是 `.jpg`，磁盘上实际都是 png，已经按实际改过来了）。
换的图尺寸不一样的话，记得把 HTML 里那个 `width`/`height` 属性一起改，
否则会先按旧尺寸占位再跳一下。

**调版面**：改 `assets/css/site.css`。桌面端的固定几何全在那一个
`@media (min-width: 820px)` 块里，基础样式保持流式。改完刷新浏览器即可，没有构建步骤。

**加页面**：照抄同语言同类型页面的骨架（`.stage` 结构 + `<link>` 到 `site.css` +
`<script src="../assets/js/site.js">`），页面宽度靠 `@media` 块里那条 `.xxx { width: Npx }` 决定。

**改缩放策略**：`assets/js/site.js` 顶上三个常量，`MIN_WIDTH`（断点，要和 CSS 里那个对得上）、
`MAX_SCALE`（放大上限）、`EDGE`（缩小时左右留的缝）。

## 与原版的已知差异（故意的，不是跑偏）

改造后用 Playwright 逐页和原版做了像素级比对（原版跑在 `D:\_elven_tools\baseline`，
是 `a4abc0a` 那个提交的 git worktree）。中文页最大偏差 0.4~1.1px，英文页 2px 上下。
剩下的差异都是下面这几处，都是原版的排版瑕疵，没有照搬：

- **英文页导航图比原版高 2px。** 原版英文页的导航按钮是行内图片，落在文字基线上被顶下去 2px，
  中文页没有这个偏移。按中文页统一了。
- **3D/2D 缩略图网格是严格的 90px 等距。** 原版表格写死 `width="545"` 却塞 6 个 90px 的格子
  （6×90=540），浏览器把多出来的 5px 摊给各列，格子间距变成 91/90 不均，
  连 90×90 的玻璃角标底图都被轻微拉伸了。按 90 走才是那张底图本来的尺寸。
- **contact 页中段高度按实测校正为 284px**（原版这里靠空的 `<td>` 和一个 282 高的嵌套表格撑着）。

## 工具目录

`D:\_elven_tools` 跟站本身无关，**整个删掉不影响浏览**。里面留了这次改造用的脚本：

- `measure.py` — 量一个页面上每个图和色块的绝对位置
- `cmp.py` — 把重建版（:8765）和 baseline（:8799）逐元素比对，报最大偏差
- `shoot.py` / `verify.py` — 批量截图 / 整站验收（控制台报错、404、横向滚动、坏图、死链）
- `baseline/` — `a4abc0a` 的 git worktree，用来跑原版做比对
- `build.py` — **已作废，别跑。** 它是这次改造之前那版生成脚本，跑起来会先把
  `D:\web_local` 整个清空，然后生成一个**没有这次改造**的版本。已改名为
  `build-obsolete.py`，以防手滑。

`D:\web` 是**原始镜像，只读，永远不要往里写**。那是唯一的一份底片。
