# ELVEN STUDIO 网站本地重建版

这是 2006 年 elvenstudio.com（成都轻灵/精灵数码，游戏美术外包公司）整站镜像的本地重建。
原始文件在 `D:\web`，全部被压平在一个目录里，HTML 里写的又是原始的相对路径，所以直接双击
打开是坏的。这个目录是重新拼装过的、可以直接浏览的版本。

> **这个目录就是成品，以后直接在它里面改，不用再跑构建脚本。**
> 换图、调 HTML 都在这儿动。重新生成的事只在下面「重建」一节，平时用不上。

## 怎么看

双击 `启动.cmd`（会起一个本地服务并自动打开浏览器），或者手动：

```
cd D:\web_local
python -m http.server 8765
```

然后浏览器打开 <http://127.0.0.1:8765/>。

必须走 http，不能直接双击 html 文件——Flash 模拟器和部分相对路径在 `file://` 下不工作。

## 目录

- `index.html` — 入口，选中文 / 英文
- `gb/` — 简体中文版
- `en/` — 英文版（镜像里这个目录叫 `zh`，但装的是英文内容）
- `assets/image/` — 全部图片。原镜像里的 184 张（HTML 里写 `.jpg`，实际文件都是 `.png`）
  加上下面那 15 张白色占位，一共 199 个文件
- `assets/flash/` — 两个原始 SWF
- `ruffle/` — Ruffle（Flash 模拟器，本地自带，离线可用，MIT 许可）
- `legacy-flash.html` — 顺带保留的 2003 年版 Flash 首页

## 改了什么

1. **路径**：原 HTML 引用 `../../gb/image/xxx.jpg` 这类原始目录结构，镜像里目录已经没了。
   现在统一指到 `assets/`。
2. **扩展名**：HTML 里写 `.jpg`，磁盘上实际是 `.png`，按实际文件改。
3. **编码**：原来是 gb2312，转成 UTF-8。
4. **语言变体**：同一张图（比如 01-bj004）在镜像里存了两份，原名是中文版、`_1` 后缀是英文版，
   按页面语言各取所需。
5. **Flash**：原页面用 `AC_RunActiveContent` 脚本塞 SWF，现在改成普通 object/embed，
   由 Ruffle 接管播放。
6. **语言按钮**：原首页（根目录和 gb 目录各一个）的"ENGLISH"按钮指向中文站、"中文"按钮指向
   英文站，反了，已调正。英文版首页原来用的是"ENGLISH"按钮，改成镜像里留着没用的
   "ENTER"按钮（`00-bj007_1.png`）。
7. **跨语言链接**：中文页 ↔ 英文页的跳转按新目录重算。
8. **水平居中**：原站三个入口页的表格带 `align="center"`，内页却是靠左的——当年目标是
   1024x768 的屏幕（3D 页正好 1024 宽，铺满一屏），左贴边等于满屏，看不出来。
   现在的宽屏下 654 宽的版面缩在左上角、右边一大片黑，所以给各顶层页面的最外层表格
   都补了 `align="center"`。另外 3D 页有两个表格写死 `width="1024"`、最外层表格里还有
   空的占位列，把它们去掉，页面按内容宽度（约 659）居中，画册、导航条、下面那条红带
   才对得上一条中线。**图上没动过一个像素，只改了版面摆放。**
   想要原汁原味的靠左版，把 `build.py` 里「水平居中」那一段删掉重跑。
   iframe 里的内容页没动。
9. **占位图**：镜像里缺的 15 张图补了同尺寸白色占位，见下一节。

## 重建（平时用不上，别手贱）

三个目录，各管各的：

- `D:\web` — **原始镜像，只读，永远不要往里写。** 这是唯一的一份底片，弄丢了就再也回不来。
- `D:\web_local`（就是这里）— **成品，日常改的就是它。** 换图直接覆盖 `assets/image/` 里的同名文件，
  改版面直接改这里的 HTML。改完刷新浏览器即可，没有"重新生成"这一步。
- `D:\_elven_tools` — 工具目录，跟站本身无关，可以整个删掉不影响浏览。

`D:\_elven_tools\build.py` 是从底片重新洗一份干净成品的脚本，读 `D:\web` 写 `D:\web_local`。
**它会先把 `D:\web_local` 整个清空**，所以现在加了防呆：目录非空时直接拒绝运行，除非显式

```
python -I build.py --force
```

也就是说，平时手滑跑一下不会出事。什么时候才需要它：这里的 HTML 被改乱了想推倒重来，
或者想把上面「改了什么」那 9 条重新套一遍。真跑的话记住两件事——**先把自己换过的图备份出来**，
以及**别再指望 `D:\_elven_tools\placeholders\` 是白图**了，那个目录里的文件重建时会被直接拷进来。
