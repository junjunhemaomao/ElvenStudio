# ELVEN STUDIO 成都轻灵数码 网站重建版

2006 年 elvenstudio.com（成都轻灵数码，游戏美术外包公司）整站的重建版。
原站开发年代久远，已不适配现代浏览器和显示器分辨率，这一版按现代网站重做。

在线地址：<https://junjunhemaomao.github.io/ElvenStudio/>

## 目录

- `index.html` — 入口，双语开场页，选中文 / ENGLISH
- `gb/` — 简体中文版：`index` `about` `3d` `2d` `contact`
- `en/` — 英文版
- `gb/gallery/`、`en/gallery/` — 044 / 045 / 046 三个项目画册
- `legacy-flash.html` — 2003 年版 Flash 首页的存档说明页
- `assets/css/site.css` — **全站唯一的样式表**，所有版面都在这里
- `assets/js/site.js` — 唯一一段脚本，只干两件事：手机汉堡菜单、作品灯箱
- `assets/image/` — 全部图片
- `assets/flash/` — 两个原始 SWF，以及从 01-f001.swf 转出来的动态 WebP

纯静态站，没有构建步骤、没有依赖。改完直接刷新浏览器就能看到。
